GonogoMechJebUplink compile-time links MechJeb2 (MechJeb2.dll). It reads and
writes MechJeb2's public API in-process; reflection is used ONLY for the
version-guard's presence/shape probe (MechJebVersionGuard.cs), never to
invoke MechJeb2. See local_docs/design/mechjeb-uplink-sketch.md and
local_docs/design/mechjeb-decompile-lock.md.

GPL-3.0-only.

gonogo as a whole is MIT-licensed (repository root LICENSE). GonogoMechJebUplink
is a deliberate exception, same as GonogoKosUplink: it is one of the few

that direction, and GonogoMechJebUplink ships as its own CKAN package in its
own GameData folder.
